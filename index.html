Four verification gates

  1. Access: DNS/TLS, authentication, model listing and exact model ID.
  2. Protocol: response structure, request ID, declared model and token arithmetic.
  3. Behavior: randomized probes, streaming, tool calls and a real workload.
  4. Production: sample size, success rate, p50/p95 latency, errors, cost and rollback.
